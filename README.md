# Cal Li Multiverse

Every film is one universe of Cal Li. Each folder has the full recipe for one film: the prompt, the image prompts, the frame-by-frame timing, the sound and every source. Paste it into any coding agent, use any image model, and make your own.

| film | length | what it is |
| --- | --- | --- |
| [Multiverse](multiverse/) | 27.5 s | One character in 53 universes. No video model was used: every frame is code. |

New films are added here when they come out.
